## Цель работы
Реализовать алгоритм умножения матриц 
C=A×B с использованием технологии CUDA, провести серию экспериментов с различными размерами матриц и конфигурациями сетки блоков, проанализировать ускорение и эффективность параллелизации на графическом процессоре.

## Технологии
- **C++** (стандарт C++11/14/17) — основная реализация алгоритма
- **Python 3** — генерация тестовых матриц и визуализация результатов
- **CUDA** - Параллельные вычисления на GPU (ядро, shared memory, events)
- **Python 3** - Генерация тестовых данных, автоматизация экспериментов, визуализация
- **NumPy** -Генерация случайных матриц
- **Matplotlib** - Построение графиков производительности
- **Google Colab** - Облачная среда выполнения с GPU (Tesla T4)

## Основные выводы

### Оптимальная конфигурация: блок 16×16

Блок размером **16×16** обеспечивает лучшую производительность благодаря:

| Фактор | Описание |
|--------|----------|
|  **Shared memory** | Плитка 16×16 = 256 элементов × 8 байт = **4 КБ на матрицу** (всего 8 КБ на блок), что идеально укладывается в лимиты shared memory |
|  **Occupancy** | Хороший баланс между количеством активных потоков и использованием регистров — позволяет скрыть задержки памяти |
|  **Глобальная память** | Минимизация обращений к глобальной памяти в `TILE_SIZE` раз за счёт кэширования в shared memory |

##  Выводы

 **Реализована корректная параллельная версия** умножения матриц на CUDA с использованием **shared memory tiling**. Алгоритм корректно распределяет вычисления между потоками и обеспечивает синхронизацию доступа к общей памяти.

 **Экспериментально подтверждена кубическая сложность алгоритма**: время выполнения растёт пропорционально $N^3$, что соответствует теоретической оценке $O(N^3)$ для классического умножения матриц.

 **Достигнуто ускорение до 7.22×** относительно последовательной версии при использовании блока **16×16** для матрицы **400×400**. Это подтверждает эффективность параллелизации на GPU для задач средней и большой размерности.

 **Оптимальная конфигурация**: `blockSize = 16`, `N ≥ 400` обеспечивает баланс между производительностью и использованием ресурсов:

| Параметр | Рекомендация | Обоснование |
|----------|-------------|-------------|
| `blockSize` | **16×16** | Оптимальное использование shared memory (4 КБ на матрицу) и регистров |
| Размер матрицы | **$N \ge 400$** | Вычислительная нагрузка преобладает над накладными расходами на передачу данных |
| Тип памяти | **Shared + Global** | Tiling снижает обращения к глобальной памяти в `TILE_SIZE` раз |
