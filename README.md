## Цель работы
Реализовать алгоритм умножения матриц с использованием технологии MPI, провести серию экспериментов с различным количеством вычислительных процессов, проанализировать ускорение и эффективность параллелизации.

## Технологии
**C++17** - Основная реализация алгоритма умножения матриц
MPI (Microsoft MPI)Распределённые вычисления, обмен сообщениями между процессами

**Python 3** - Генерация тестовых матриц, автоматизация экспериментов, визуализация


**Matplotlib** - 
Построение графиков зависимости времени, ускорения и эффективности

## Выводы
1. **Реализована корректная параллельная версия** алгоритма умножения матриц с использованием технологии **MPI**. Применена стратегия распределения данных по строкам: каждый процесс получает часть строк матрицы $A$ и полную матрицу $B$.

2. **Экспериментально подтверждена теоретическая сложность** алгоритма $O(N^3)$: при увеличении размера матрицы в 2 раза время выполнения возрастает примерно в 8 раз (для последовательной версии).

3. **Достигнуто ускорение до 6.69×** при использовании 8 процессов для матрицы размером $400 \times 400$. Это свидетельствует о высокой эффективности параллелизации для задач среднего размера.

4. **Пиковая производительность** составила **14.53 GFLOPS** (матрица $200 \times 200$, 8 процессов), что объясняется лучшим использованием кэш-памяти при работе с небольшими объёмами данных.
